TENOTEMO EARN PILOT — INSTALLATION

1. Existing prerequisites: tenotemo_normal_games_migration.sql and tenotemo_spotlight_migration.sql must already be installed in the SAME Supabase project used by index.html. Existing authentication, Premium and Spotlight remain.
2. Run tenotemo_earn_migration.sql in Supabase SQL Editor. It creates separate Memory Credits, company package and campaign tables, private earnings records, secure credit claims and admin-only approval functions. It revokes direct authenticated execution of legacy daily cash-prize settlement functions. Historical award rows are NOT deleted. Audit any other server-side triggers/cron jobs that may still call legacy settlement.
3. Deploy index.html, tenotemo-spotlight.js, tenotemo-versus.js, tenotemo-earn.js, and api/r.js to your Vercel project's ROOT (api/r.js stays in api/). Keep the existing project's build settings.
4. In Vercel server-side Environment Variables set SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, and TENOTEMO_REFERRAL_SALT (long random secret). Never expose service role key in client-side HTML/JS or GitHub. Redeploy after saving environment variables.
5. For company setup: company registers an ordinary Tenotemo account, submits a Spotlight post with approved HTTPS destination, pays agreed company package by EFT; admin verifies funds, approves post, grants package and creates campaign from Tenotemo Earn admin controls. Company exposure is added to existing purchased Spotlight views (100 views per credit). Campaign reward budgets are accounting limits; verify actual company funding separately before approving player rewards.
6. Players claim previous completed days (within 30 days) in Tenotemo Earn. A score >0 in a normal game is used as a provisional completed-challenge signal; improve server-side completion verification before large-scale use. Ranking bonus is based on the final previous-day active-player ranking. Existing normal-game scores are client-submitted and should be fraud-audited.
7. Share & Earn uses /api/r?code=... links. Vercel function redirects to approved HTTPS company link and records one indicative visit per referral/device-signature/day. It CANNOT prove a WhatsApp/Facebook Status was posted, a sale occurred, or a human saw an ad. Do not automatically award cash for clicks. Manual admin rewards must have independently verified evidence.
8. Admin-approved earnings are private to each player. Cash transfers are MANUAL, and the paid status can be set only through admin-only tenotemo_admin_reward_paid(p_reward_id) RPC after confirming EFT. Pilot UI does not automate payouts.
9. Company packages: Starter R500/50 Spotlight credits; Growth R1500/200; Premium R5000/750. These are proposed commercial prices, not automated subscriptions. Premium PLAYER R50/month is unchanged.
10. Run a controlled pilot and obtain appropriate SA legal, tax and privacy review before paying cash or promoting earnings claims. No guarantees of income.
