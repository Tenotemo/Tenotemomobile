TENOTEMO — MANAGE PUBLISHED CAMPAIGNS

1. First install the earlier smooth campaign SQL and picture/video SQL if not already installed.
2. Run tenotemo_manage_published_campaigns.sql in Supabase SQL Editor.
3. Upload index.html, tenotemo-earn.js, tenotemo-spotlight.js, tenotemo-versus.js and api/r.js from this ZIP to the existing GitHub repo, preserving api/. Do not upload SQL files to GitHub.
4. Refresh site, open Tenotemo Earn > Advertiser campaign administration > Manage Published Campaigns.
5. Edit, replace media, pause, resume, or end linked campaigns.

The new editor does not change allocated reward budget or delete financial/referral records. A paused campaign disappears from Spotlight and cannot be newly unlocked; existing referral codes and records remain. End is irreversible. Old media files are retained for audit. Existing standalone Spotlight posts not linked to Earn are not in this list.

Not tested against your live Supabase project.
